# Contributing

Thanks for helping! Before your first pull request is merged, please agree to the
contributor terms below by writing **"I agree to the CLA"** in the pull request.

This keeps the project able to offer both the AGPL community edition and a commercial licence.

## Rules

- Never commit real company data, credentials, tokens or customer names. Use the Contoso demo data.
- Keep pull requests small and explain *why*.
- Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).
